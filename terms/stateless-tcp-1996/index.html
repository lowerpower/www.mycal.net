Stateless TCP (1996)

First implemented: 1996  ·  iReady Corporation, Petaluma CA

Definition

The first FPGA-based hardware implementation of a stateless TCP state machine, built at iReady Corporation in 1996 using hand-wrapped Xilinx FPGA connections. Implemented the Stateless TCP concept (coined 1995) in reconfigurable silicon, forming the foundation of the iReady silicon TCP product line which was ultimately acquired by NVIDIA in 2001.
